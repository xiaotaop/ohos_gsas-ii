# 许可证与上架风险审查

本审查基于锁定提交的根目录 `LICENSE`，仅作工程合规清单，不构成法律意见。GitHub 对主许可证的自动识别为 Other/NOASSERTION；不应将其简写为 MIT、Apache-2.0 或 GPL。

## GSAS-II 主许可证

根目录 `LICENSE` 原文已保留。分发时需保留版权/免责声明；修改应标明修改内容和作者/组织；分发修改作品意味着允许原版权人将修改纳入后续 GSAS-II 版本；含二进制的分发需随附全部相关源码并在文档/材料中重现声明；不得暗示 UChicago Argonne、DOE 或贡献者为衍生产品背书；软件与终端用户文档需包含 `NOTICE` 中的原文致谢。

## 上架前必须完成

1. 逐文件建立最终安装包 SBOM/第三方组件清单；收集各组件许可原文与源码获取方式。
2. 对 DIFFaX 和 Shapes 确定“可分发”或“明确排除”的书面结论，并验证构建依赖链。
3. 对 Python、NumPy、SciPy、PyCifRW、UI 框架及任何静态/动态链接库执行版本和许可审查。
4. 让最终 README、应用内关于页面、商店描述及随包文档包含正确的许可证和 `NOTICE`。
5. 对修改过的上游文件逐项标注修改作者/组织、差异和许可；不可删除原有声明。

授权门槛未关闭前，不发布安装包、不提交“已具备上架条件”的结论。
