# GSAS-II HarmonyOS PC 操作说明

适用：正式 `app/` 的 0.1.0 开发版及指定设备 internaltesting 签名包。当前支持 PbSO4 五文件组合的五阶段精修界面；未开放的菜单呈灰色。运行任务需要包含真实计算运行时的安装包。HAD-W32/API23 上的签名包已验证五阶段、成功任务的 GPX/JSON/日志导出和重启恢复；取消、失败日志及其他设备兼容性尚未在同一签名包完成验收。本说明不是公开上架承诺，范围见[验收矩阵](RELEASE_ACCEPTANCE.md)。

## 1. 界面与导航

- 顶部是 File、Data、Calculate、Import、Export、Help 菜单；左侧是输入数据树，右侧显示选中页面。
- 拖动中间分隔条可调整数据树宽度；树和右侧页面可分别滚动。
- 浮动窗口最小尺寸设为 640 × 480 vp；屏幕缩放会影响对应的物理像素。内容较长时在相应区域滚动，不需要把整个页面一次显示完。
- **Ctrl+R** 打开精修任务页，**F1** 打开帮助与版本；**Tab / Shift+Tab** 切换可聚焦控件。菜单打开后可用方向键、Enter 和 Esc 操作。
- File → Imported files 打开文件库；File → Input associations 或树顶端 Loaded Data 打开五个输入槽位。
- 当前不支持打开或保存已有 GPX 工程、完整科学参数解析、绘图编辑器、自定义 recipe 或并行精修。顶部 Export 菜单中的原版格式转换项尚未开放；可用导出入口在文件库和任务结果中。

## 2. 导入与关联五份输入

在 Loaded Data 页面逐项点击 Import，或从对应下拉框选择已导入文件：

| 输入用途 | 标准 PbSO4 文件 |
|---|---|
| X 射线粉末数据 | `PBSO4.XRA` |
| X 射线仪器参数 | `INST_XRY.PRM` |
| 中子粉末数据 | `PBSO4.CWN` |
| 中子仪器参数 | `inst_d1a.prm` |
| 相文件 | `PbSO4-Wyckoff.cif` |

导入会复制到应用文件库，原文件不变。取消选择保留原关联；重新选择也不会删除旧副本。相同文件名的不同导入副本仍是不同文件，选择时应核对用途和文件信息。

点击 **Check input files** 检查五项关联、文件存在性与完整性。检查通过不等于科学格式或精修验收通过。关联正常保存后，重新启动应用可恢复；若提示关联保存失败，应在下次启动后重新确认。

Import → Powder Data 可选择 X-ray 或 Neutron 用途；Import → Phase 可导入 CIF。文件库中的通用导入只增加副本，之后还需到 Loaded Data 关联到相应槽位。

## 3. 填写并启动精修

1. 按 Ctrl+R 或选择 Calculate → Refine。
2. 确认计算服务已就绪。若显示 `RUNTIME_NOT_PACKAGED`，当前安装包缺少运行时，需取得完整集成包；反复重试不会补装载荷。其他初始化错误可使用 **Retry initialization**。
3. 明确填写相名、**Max cycles（0～50 的整数，无预设值）**和以 `.gpx` 结尾的输出文件名。文件名不含目录路径；相名不能仅凭 CIF 文件名推断。标准基线验证时按团队约定参数填写。
4. 点击 **Refine**。开始前再次校验输入，运行时显示阶段、进度和任务消息。服务未就绪或输入操作尚未结束时，按钮不可用。

任务表单在本次页面切换和初始化重试后保留；不承诺退出应用后的跨进程保存。

## 4. 取消、错误与结果

- 点击取消后先进入“正在取消”，等待当前计算阶段结束和核心终态；这不是强制终止。若完成与取消同时发生，以核心最终报告为准。
- 失败时显示错误码和可读说明。按提示修正输入／参数或重试，不把旧结果当成新任务结果。界面不应显示 Python traceback。
- 成功后查看五阶段 Rwp、耗时、择优取向及基线校验状态。只有实际执行并通过校验才显示通过。
- 结果或失败／取消日志旁的 **Export...** 打开系统保存选择器；保存完成后才提示已导出。取消保存会提示已取消。
- “任务消息”是屏幕消息，不等于可下载日志。只有核心返回已登记产物时才有导出入口；失败／取消未提供日志时显示“本次终态未提供已登记的日志，没有可导出的日志文件”，不从文件名推导日志。
- 文件库的 **Export copy...** 可导出已有输入或产物副本。同名目标由系统选择器处理；不想替换时取消选择。

未装配真实运行时的开发包仍无法计算；指定设备签名包已验证成功任务的计算、产物导出及进程重启恢复。失败／取消日志的真机可发现与导出仍待补验。B 的终态持久化已接入：服务就绪且记录有效时，可恢复最近任务的终态摘要和已登记产物；这不会恢复旧计算，也不会重建历史消息。旧任务记录不存在时页面允许新任务并提示到文件库查找旧产物，不代表旧任务已恢复成功。活动任务中断和后台生命周期仍待同包验收。

## 5. 本地草稿和笔记

Controls、Limits、Background、Instrument Parameters 和 Sample Parameters 的 **Edit local draft...** 仅编辑本地草稿，不改写输入文件、不自动提交精修。真正提交的参数在任务页填写。

- **Save local draft**：保存当前草稿。
- **Cancel**：放弃本次编辑，保留原草稿。
- **Clear form**：只清空编辑表单；保存后才覆盖旧草稿，Cancel 可撤销本次清空。
- Notebook 是应用本地笔记；Comments 是对应粉末副本的本地备注，不表示已解析原文件注释，也不写入 GPX。

其他参数草稿按输入关联隔离。切换关联可能看到另一份草稿；卸载前自行留存需要的笔记。

## 6. 文件管理与退出

文件库可按文件名、fileId 或 SHA-256 搜索，并按类型筛选；**Clear filters** 清除筛选。**Delete copy...** 先要求确认，仅删除应用副本及其输入关联，不删除原始文件。任务活动期间禁止删除或重选输入。

通过 File → Exit 或系统关闭按钮退出。初始化、文件操作或任务尚未结束时应提示返回应用；取消任务也须等到终态后退出。应用处于后台时任务应继续执行。进程被终止后不自动继续旧计算，未完成任务应显示中断；这些真实任务生命周期行为仍待集成包验收。

文件库中的 **Run file service checks** 是开发验证入口，普通使用不需要执行。
