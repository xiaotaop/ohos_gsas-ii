# 晶衍精析隐私政策

更新日期：2026 年 10 月 21 日。生效时间：随本应用首次公开发布生效。

发布者及维护者：**朱宇辰**。本政策适用于晶衍精析 HarmonyOS PC 应用（包名 `com.gsasii.desktop`），当前版本为 0.1.3。计划分发地区为中国大陆。

晶衍精析是基于 GSAS-II 的非官方移植，用于在本地处理粉末衍射数据。本政策说明应用处理哪些数据、用途、保存方式，以及您如何管理数据或联系维护者。

## 1. 处理的数据与用途

您主动使用系统文件选择器导入的 X 射线/中子粉末衍射数据、仪器参数和 CIF 文件，用于解析、关联输入及本地精修计算。应用在设备的应用存储空间保存以下内容：

- 导入文件的副本，以及文件名、类型、大小、完整性校验值和文件索引，用于文件管理和校验。
- 输入文件关联、计算参数草稿和笔记，用于编辑及恢复工作状态。
- 任务标识、时间、进度、状态快照、计算结果、错误信息和任务日志，用于显示计算过程、导出及重启恢复。

输入文件、文件名、笔记和日志可能包含您自行写入的个人信息或保密科研资料。请只导入您有权处理的文件；向他人分享前请核对并删除不必要的信息。不导入相关文件时，相应计算功能无法执行，您仍可决定是否使用该功能。

## 2. 本地计算、权限与第三方组件

本版本不提供应用账号注册登录、广告、支付或用户行为统计服务。已实现的工作流程不要求将输入文件和计算结果上传至开发者服务器，也未配置开发者的数据接收服务器。应用入口清单未声明网络、位置、相机、麦克风或通讯录请求权限；文件访问通过系统选择器逐次取得用户所选文件的授权，不等于访问设备上的任意文件。

应用包含 GSAS-II、CPython、NumPy、SciPy、PyCIFRW 及其数值计算依赖，用于本地文件解析和计算；当前工作流程未将这些组件用作广告或个人信息分析服务。组件版本、来源与许可证见应用内第三方许可及交付的 SBOM、源码和通知材料。上述说明描述本版本实现的流程，不将清单中未申请权限等同于对所有第三方代码任意场景的网络行为保证。

应用市场、操作系统的下载、安装、签名验证和系统服务由相应服务提供者按其隐私政策处理，不属于本应用开发者自行接收的数据。

## 3. 保存位置、期限与安全

导入副本、索引、草稿、笔记、任务及结果保存在设备的应用存储空间，没有开发者云端同步功能。本地数据会在您使用期间保留，直至通过可用的文件管理功能删除，或由系统清除应用数据、卸载等操作清理；应用未设置统一的自动到期删除期限。

应用使用系统应用存储隔离、文件授权及完整性校验等机制保护数据。请妥善管理设备访问权限并备份重要研究结果。设备丢失、系统故障或误删除可能导致数据丢失。

## 4. 导出、共享与第三方网站

GPX、JSON 和日志由您主动通过系统保存对话框导出至所选位置。导出副本由您及目标位置的管理者控制；若选择云盘等位置，后续存储或同步受该服务规则约束。本应用不会因为您导出文件而自动将其提交给维护者。

当前工作流程没有向开发者或广告服务自动出售、共享或转让输入文件、计算结果的功能。如您自愿在 GitHub Issues 提交反馈，GitHub 将按其[隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement)处理账号、访问和提交内容。Issues 是公开页面，阅读无需登录，发帖通常需要 GitHub 账号；本应用的本地计算不依赖 GitHub 登录。

## 5. 您对数据的管理

您可以选择不导入文件、取消任务、导出结果，并通过应用提供的文件管理功能删除未被活动任务引用的文件。文件管理中的单项删除不等于清除所有草稿、任务和日志；需要完整清理时，请先导出需保留的结果，再使用系统提供的应用数据清理或卸载功能。活动任务引用的文件可能暂时无法删除。

本地原始输入和已导出的外部副本需要您在对应位置另行管理，卸载应用不会替您删除这些外部副本。本应用没有线上账号，因此没有应用账号注销流程。您可以停止使用应用并管理本地数据；本地副本不向维护者开放远程访问，维护者不能代您读取或删除设备内文件。

如需咨询个人信息访问、更正、删除或对处理方式提出异议，请通过下述联系入口向朱宇辰提出。反馈中的个人信息仅用于理解和处理您主动提出的问题，不作为广告用途。公开 Issue 中已提交的内容可按 GitHub 提供的编辑、删除和隐私请求机制管理；引用、缓存和他人副本可能不随原帖删除而消失。

## 6. 未成年人

本应用是科研计算工具，不专门面向儿童，也不要求填写年龄、身份或未成年人信息。未成年人应在监护人指导下使用，不应在输入文件、笔记或公开反馈中提交不必要的个人信息。监护人如发现相关信息被不当提交，可通过联系入口请求协助处理。

## 7. 政策更新

数据处理方式发生变化时，将在本政策的公开页面更新日期与内容；如变化涉及需要告知或征得同意的事项，将按适用要求处理。未来版本如增加联网、账号或其他数据处理功能，将据实际实现更新说明，不将本版本政策自动扩大适用。
